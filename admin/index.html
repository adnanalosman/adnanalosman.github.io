مراجعة التعديلات ونشرها

ستُحفظ التعديلات في المستودع العام، ثم يُحدّث GitHub Pages الموقع. راجع النصوص في اللغتين قبل المتابعة.

إعداد صلاحية النشر لأول مرة
  1. افتح إعدادات GitHub ثم Developer settings → Personal access tokens → Fine-grained tokens.
  2. أنشئ رمزًا بتاريخ انتهاء مناسب، واختر Only select repositories ثم مستودع adnanalosman.github.io فقط.
  3. ضمن صلاحيات المستودع، امنح Contents: Read and write. لا تحتاج اللوحة صلاحيات الإدارة أو سير العمل.
  4. انسخ الرمز إلى الحقل أدناه. لا تضعه في ملفات الموقع أو ترسله في المحادثة.
